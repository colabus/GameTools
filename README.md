# \# GameTools

# 

# A small collection of tools for tweaking games, experimenting with game memory, and making a few things work the way I want them to.

# 

# These are simple utilities built around specific games and features. The aim is to keep each tool focused and easy to use.

# 

# \## AI-generated code

# 

# Much of the code is generated with AI assistance. This project is also an experiment in using AI to build practical tools, troubleshoot problems, and refine ideas.

# 

# Expect rough edges. A tool working with one game version doesn't guarantee it will work after an update.

# 

# \## Using the tools

# 

# Check the instructions included with each tool for setup, supported features, and usage. Tools that change game memory depend on the game version and may need updating when the game changes.
